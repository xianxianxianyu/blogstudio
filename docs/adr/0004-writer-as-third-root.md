# ADR-0004：Writer 是外壳的第三个根，稿子与书在同一列案头上

## 状态

Accepted（2026-08-20）

## 背景

Reader 与 Context 两侧都在了：读 PDF、摘录入库、把 context 连成图。**输出这一头还是空的**
——`docs/workflow.md` 设计了一整套写作工作流（三种模式、两道闸门、eval ⇄ revise 循环、
任务即图），但那套东西的前提是**先有一个能把字写下去的地方**。

决策者要的很具体：一个与 Reader、Context 并列的 **Writer**，主页面是好用的所见即所得
markdown 编辑器，右边一栏是问答，形态与阅读页的「问文档」一样。

## 决策 1：第三个根，不是 Reader 的子页面

ADR-0003 决策 3 定下的联合是开放的，这次只是多两个分支：

    type Active =
      | { kind: "shelf" } | { kind: "context" } | { kind: "writer" }   // 三个根
      | { kind: "doc"; id } | { kind: "draft"; id }                    // 打开的东西

读、想、写是三件事，不是「读」底下的三个功能。把 Writer 塞进 Reader 里，层级又会反一次
——那正是书架当初从阅读页侧栏里搬出来的理由。

外壳的判据一个字没松：**它仍然不 import 任何一边的领域类型**（`Clip` / `Section` /
`Context` / `Draft` 一个都没有）。

## 决策 2：稿子和书混在同一列案头上

ADR-0003 决策 3 预告过这一下（「Context 那侧长出可以开着的东西时，它和书一样进同一列」），
稿子就是第一个兑现它的。**不按类型分组、不加第二列**——分组等于把被否掉的「模式」
又装回来。一行前面一个小图标就够了。

`DeskItem` 因此变成一个联合：

    | { kind: "doc"; id; page; pane }   // 书要记住第几页、右栏开着哪一栏
    | { kind: "draft"; id }             // 稿子什么都不记

**稿子不记位置，是决定不是遗漏**：光标和滚动在编辑器自己手里，外壳插手只会把它顶掉。

关掉案头最后一项时回**它自己那一侧的根**：关掉最后一篇稿子落到书架上，等于把人从写作里
一脚踢回阅读。

## 决策 3：一篇稿子就是一份 markdown，不是块数组

`docs/workflow.md` §2.2 设计的 Draft 是 `blocks[] + provenance + revision`。那套结构是给
**Loop**（agent 自己改、改动要能审）用的，而现在还没有 Loop，只有人在编辑器里写。

先落一份 markdown：`<library>/../drafts/<id>.md`，frontmatter 放机器读的，`---` 之后原样
就是正文（ADR-0011 的形状）。**把一个 `.md` 丢进那个目录就能在 Writer 里打开**，不用导入
——写文章的人本来就有别的编辑器。

代价写在这里：等 agent 真的开始动文本，block 级 provenance 与 revision 得补上，那时这层
存储要改。反过来（先建模、再实现编辑）意味着第一天就要维护一套没人读的结构。

## 决策 4：右边那栏是 chat，与「问文档」同一个形状

`docs/workflow.md` §3.2 写的是「Studio 里没有 chat 面板，只有一个悬浮 composer」。
**这一版不照那条走**，理由是它的前提还不成立：那条规矩要的是「回答落回正文对应位置」，
而落回正文需要 Diff / provenance / 持笔锁那一整套，一样都还没有。

在没有那套东西之前，一个常驻的 chat 栏是诚实的形态：它**只说，不动正文**（§1.3 的规矩
——改动要么当场被人看见，要么进 review，中间地带不存在；人自己粘进去的那一下就是「当场
看见」）。等 Diff 落地，这一栏可以按 §3.2 收成悬浮的。

材料给到两层：**整篇稿子**（几千字，整篇进 prompt 比检索更准）＋**从知识库召回的 context**。
召回不按 topic 查（§4④ 已经写死），按语义；**召不到就明说召不到**，宁可一条不给也不硬凑
——硬塞几条不相干的进去，模型会围着它们认认真真地写，而写文章的人看不出那几条是凑数的。

出处要显眼且可点，与 Reader 那侧同一条硬要求：引用了哪条 context 就摆出哪条
（§1.5：不存在既无 provenance 又未标记 authored 的断言）。

## 代价

1. **稿子的对话不跨稿子**（换一篇就清空），与 Reader 的单文档封闭同一口径。代价是换回来
   之后上一场对话没了。
2. **召回的阈值没有量过。** 相对判据（尖峰高出中位数多少）是从 PDF Studio 那次 eval 抄来的
   形状，但那个数字是在论文检索上扫出来的。Blog Studio 还没有对应的评测集。
3. **Vue 进了包。** 编辑器选型见 `blogstudio/docs/adr/0001`。
