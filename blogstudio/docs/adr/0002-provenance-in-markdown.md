# ADR-0002：出处的记号住在正文里，版本靠追加而不是覆盖

## 状态

Accepted（2026-08-20）

## 背景

`docs/workflow.md` 有两条规矩，是整套 eval ⇄ revise 循环的地基：

> §1.5 每个断言要么有 provenance，要么标记 authored。
> §2.2 Revision 是线性追加的，不覆盖。任何一轮都能被取回。

而它设计的数据结构是 `blocks[]`——每一块有 `block_id`、`provenance`、`author`。
问题在于：稿子在磁盘上是一份**可以拿别的编辑器改的 markdown**（ADR-0004 决策 3），
块没有稳定的身份。

## 决策 1：出处写在正文里，不写在旁边的表里

一段话的末尾写 `[ctx:xxx]`（引了这条材料）或 `[authored]`（我自己的观点）。

为什么不是「frontmatter 里存一张 blockId → provenance 的表」：那张表要靠位置或内容
哈希锚回段落，而**改一个字就失配**。失配的时候不会报错，只会把出处安到别的段落上——
一份带着错误出处的稿子，比一份没有出处的稿子糟得多。

写在正文里的三个后果都是好的：

1. **手改不会坏。** 记号跟着那段话一起被剪切、粘贴、删除。
2. **是同一个记号。** 写作搭子在对话里引材料用的就是 `[ctx:id]`（`writer-chat.ts`），
   人把那段话粘进正文，出处**跟着一起进来了**——不需要再做一次「登记出处」的动作。
3. **看得见。** 它就在句子后面。旁边表里的出处，人不会去看。

代价：记号是正文的一部分，发布时要过滤掉。这件事留给发布那一步，**不在写作时藏起来**
——写的时候看不见出处，人就不会去维护它。

## 决策 2：断言的单位是段落与列表项

不是句子：一句一句要出处，写出来像论文的参考文献表，而人真正在做的判断是「这一段站得住吗」。

不算断言的：标题（是结构不是主张）、代码块、表格、分隔线、**引用块**。最后一个是可争议的
——引文显然该有出处，但它后面几乎总跟着一段解释，两段都标就成了重复劳动。所以引文跟着
它的解释走。

## 决策 3：取回旧版也是追加一版

`restore(n)` 做三件事：**先把当前正文留成一版**、换上第 n 版、再留一版记下「取回第 n 版」。

不这么做的两个坑，都是实的：

- 直接覆盖，则「取回」这个动作自己不可撤销——而 §6 说迭代是会退步的，取回本身也可能是错的。
- 不先留当前版，则还没留过版的正文会被吃掉。人按「取回」时并不觉得自己在丢东西。

版本号**从磁盘上已有的算**，不从内存计数器算：应用重启后计数器归零，而文件还在，那会让
新版本覆盖掉第 1 版且不报错。

## 决策 4：确定性检查里一行模型调用都没有

§5.1 那张表是「不用 LLM」的检查。这一层因此是**纯函数**（正文 + 库进去，报告出来）：
没有 IO、没有端点、不需要在设置里长出旋钮（`docs/adr/0005` 那条门槛在这里正好用不上）。

落地了六条：没表态的断言（阻断）、引的 context 不存在（阻断）、空章节（阻断）、
引了有争议/已否决的材料（标记）、重复段落（标记）、过长段落（标记）。

**没落地的三条，以及为什么：**

| §5.1 的检查 | 现状 |
|---|---|
| 链接可达 | 要发网络请求，就不再是纯函数了。等有「发布前检查」那一步时再做，它本来就属于那一步 |
| Frontmatter schema | 稿子的 frontmatter 由 `draft-store` 写，坏了它当没有 frontmatter 处理。等 frontmatter 里真的有人写的字段（标签、发布时间）时再检查 |
| 长度分布 | 简化成了「单段超过 400 字就标记」。真正的分布检查要有一批本人旧文当基准，那是 §5.2 的 style anchor 那条线的事 |

**报告不拦保存。** 它说的是「这篇能不能发」——写到一半的稿子当然是红的，那是正常状态。
做成保存的前置条件，人只会学会绕过它。

## 代价

1. **两个阈值是手感值**：多像算重复（0.72）、多长算太长（400 字）。没有评测集，写成常量
   等着被量出来的数字替换。
2. **`[authored]` 可以被滥用**：一路点「这是我自己的观点」，报告就全绿了。这是设计如此
   ——§1.5 要的是「表过态」，不是「有出处」。判断观点站不站得住是 §5.2 的事，那要模型。
3. **块级 provenance 还是没有。** 一段话引了三条材料，看不出哪一句对应哪一条。等 agent
   真的开始改文本、需要「这一句的依据变了」这种粒度时再说。
