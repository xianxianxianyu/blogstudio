# ADR-0020：入库不再要求 evidence——出处是底线，逐字引文是加分

## 状态

Accepted（2026-08-20），收窄 ADR-0011 之后 `promote` 的两条守卫

## 背景

`promote` 现在有两条守卫：

    if (clip.state !== "ready")     denied("还没识别完成，不能入库。")
    if (clip.sourceText === null)   denied("纯图摘录没有原文，无法作为 evidence 入库。")

**ADR-0019 把第一条变成了死路。** 松手不再自动识别之后，图区摘录停在 `capturing`，
`ready` 只有认过才到得了——照现在的代码，新主路径下的摘录**一条都入不了库**。

第二条则是一个更早的判断：没有逐字引文的 context 不该进知识库。决策者的看法是
「evidence 可有可无，有书名 + 第 N 页就行，agent 要用我到时候做 RAG」。

## 决策

**入库只要求两样：一句断言，一个能回跳的出处。** evidence 可以是空的。

- `state !== "ready"` 这条守卫去掉：`capturing` 是「已框选、待识别」，它有锚点、有截图，
  出处是齐的。
- `sourceText === null` 这条守卫去掉：没有逐字引文的 context 仍然可回溯——
  `Source` 是结构化的（docId + 书名 + 页码），点一下就翻回去。

**有原文时仍然一定拷贝并冻结。** 那是免费的，而且冻结正是 evidence 的意义所在：
摘录后来被改、被删、被回收，这条 context 引的还是当初那句话。

## 代价，而且这条要写清楚

**空 evidence 会随时间变得更贵。** ADR-0012 说没标记为重要的摘录 7 天后衰减成墓碑——
内容删掉，只留锚点。那之后：

| | 有 evidence | 空 evidence |
|---|---|---|
| 想看当初引的是哪句 | 直接看 | 翻回那一页自己找 |
| 那一页是扫描件 | 直接看 | **重新 OCR，本机二十秒起** |
| 页码只精确到「第 62 页」 | 无所谓 | 一整页里自己认 |

所以界面上**不能默默地存一条空 evidence**：没有原文时要就地给一个「认一下」的出口
（`recognizeClip` 已经有了），让读者知道现在花十几秒可以把这句话永久钉住。

**这不是劝阻，是标价。** 决策者说的 RAG 那条路是成立的——只是它的成本落在将来，
而不是现在。

## 边界

- **evidence 仍然不允许改写。** 有就是逐字的，没有就是空的，中间没有「转述一下」。
  转述发生在消费端（术语表：证据）。
- **出处不能空。** 它是「可回跳」这条硬标准的唯一载体，空了这条 context 就是无源之水。
